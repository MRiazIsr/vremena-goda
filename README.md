# Сайт туроператора «Времена года»

Одностраничный сайт на чистом HTML, CSS и JavaScript. Сборка и сервер не нужны: сайт работает на любом хостинге, включая бесплатный GitHub Pages.

## Что где лежит

| Файл / папка | Что внутри |
|---|---|
| `index.html` | Главная страница со всеми блоками: шапка, главный экран, приветствие, «О компании», направления, галерея, контакты, подвал |
| `privacy.html` | Политика конфиденциальности (152-ФЗ) |
| `consent.html` | Согласие на обработку персональных данных (отдельный документ, как требует закон) |
| `credits.html` | Авторы и лицензии фотографий |
| `css/style.css` | Оформление. Цвета и шрифты задаются в начале файла, в блоке `:root` |
| `js/main.js` | Меню, слайдер, фильтр туров, формы заявок, галерея. **Настройки — в начале файла** |
| `img/` | Фотографии в полном размере (для главного экрана и галереи) |
| `img/thumb/` | Уменьшенные копии тех же фото (для карточек, ширина 900 px) |
| `img/logo.svg` | Логотип (он же значок вкладки браузера) |

## Как посмотреть сайт у себя на компьютере

Откройте `index.html` двойным щелчком. Всё, кроме отправки формы, работает и без интернета.

## Как подключить почту для заявок

Заявки отправляются на e-mail через бесплатный сервис [formsubmit.co](https://formsubmit.co). Регистрироваться там не нужно.

Почта уже указана в начале файла `js/main.js`:
```js
formEmail: '390699@mail.ru',
```

Нужно один раз активировать форму:
1. Отправьте с опубликованного сайта пробную заявку.
2. На 390699@mail.ru придёт письмо **«Activate Form»** от FormSubmit. Если его нет во «Входящих», проверьте «Спам». Нажмите в письме кнопку активации.
3. С этого момента заявки будут приходить письмами.

Чтобы поменять почту, впишите в `formEmail` новый адрес и снова пройдите активацию.

После активации formsubmit пришлёт случайную строку-псевдоним. Её можно вписать в `formEmail` вместо адреса, чтобы почта не была видна в коде сайта.

Пока почта не указана или сервис недоступен, форма не теряет клиента: она предлагает отправить ту же заявку в WhatsApp на +7 911 459-06-99 с уже заполненным текстом.

## Как поменять тексты, туры и фото

- **Тексты** правятся прямо в `index.html`. Блоки подписаны комментариями (`<!-- 3. О компании / Преимущества -->` и т.д.).
- **Карточки туров** — это блоки `<article class="tour-card">` в разделе «Направления». Чтобы добавить тур, скопируйте любую карточку и измените картинку, название, текст, длительность и значение `data-tour="…"`. Новый тур сам появится в выпадающем списке формы.
- **Цены.** Вместо «Цена по запросу» можно написать, например, `от 2 500 ₽`.
- **Категория для фильтра** задаётся атрибутом `data-cat`: `city` — Калининград, `coast` — побережье, `east` — замки и форты.
- **Фото.** Замените файл в `img/` и такой же уменьшенный файл в `img/thumb/` с тем же именем. Оптимальный размер: 1800 px по ширине для `img/` и 900 px для `img/thumb/`. Если ставите свои фотографии, уберите их строки из `credits.html`.

## Публикация на GitHub Pages (бесплатно)

1. Создайте репозиторий на github.com и загрузите в него все файлы этой папки.
2. Откройте **Settings → Pages**, в поле *Source* выберите *Deploy from a branch*, затем ветку `main` и папку `/ (root)`.
3. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

**Свой домен** (например, `vremena-goda39.ru`) можно купить у любого регистратора (REG.RU, Timeweb, Beget и т.д.) примерно за 200–900 ₽ в год и подключить в том же разделе **Settings → Pages → Custom domain**. Инструкция: https://docs.github.com/ru/pages/configuring-a-custom-domain-for-your-github-pages-site

## На что обратить внимание до запуска

- **Тексты.** Описания туров, длительности и преимущества написаны как черновик по общедоступной информации о регионе. Проверьте, что они соответствуют вашим реальным программам.
- **Персональные данные (152-ФЗ).** Политика и согласие подготовлены по типовой схеме. Их стоит показать юристу. Отдельно учтите, что formsubmit.co, GitHub и шрифты Google — зарубежные сервисы, а закон требует первичной записи данных россиян на серверах в РФ и уведомления Роскомнадзора об обработке персональных данных. Самый надёжный вариант на будущем этапе — российский хостинг с PHP-отправкой формы.
- **Фотографии** взяты с Wikimedia Commons по свободным лицензиям. Условие лицензий — указание авторов, поэтому страницу `credits.html` и ссылку на неё в подвале удалять нельзя, пока на сайте стоят эти фото.
